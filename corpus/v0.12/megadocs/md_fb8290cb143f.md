The mode declaration %! pappend_det6(+Left,+Right,-Out). fixes which arguments must be ground on entry to pappend_det6. The base clause pattern pappend_det6([],Right,Right). handles the terminal case where the list-structured input has been fully consumed. The recursive clause pappend_det6([Head|Tail],Right,[Head|Out]) :- pappend_det6(Tail,Right,Out). matches one element off the head and recurses on the tail. With the cut excluded and occurs check enabled, this gives a unique proof tree per input.
